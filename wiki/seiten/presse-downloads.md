# Presse / Downloads

[Übersicht](../README.md) › [Seiten-Katalog](README.md) › Presse / Downloads

**Route:** `/presse, /downloads`

**Wofür:** Logos, Fotos, Boilerplate, Zahlen, Akkreditierung, Ansprechperson.

**Daten:** Statisch plus Zips.

**Sinnvoll, wenn:** Presse eine Zielgruppe ist.

**Eher nicht, wenn:** Ein Media-Kit-Zip im Footer reicht.

## Typischer Aufbau

Reihenfolge und Auswahl sind Beobachtung, keine Vorschrift. Jede Zeile ist eine Section aus dem
[Section-Katalog](../sections/README.md).

1. [Hero / Seitenkopf](../sections/hero.md) · Seitenkopf mit Ankern
2. [Galerie](../sections/galerie.md) · als Media-Kit: Logos, Fotos, Boilerplate
3. [Presse-Karten / Bekannt aus](../sections/presse-karten.md) · Mitteilungen oder Bekannt aus
4. [Ansprechpersonen](../sections/ansprechpersonen.md) · Presse
5. [Footer](../sections/footer.md)

## Varianten

Brand-Richtlinien als Seite; Vorlagen-Paket; Akkreditierungsformular.

## Hinweise

Downloads als Zip mit Download-Zeile (Name, Format, Größe), nicht als Einzeldateien. Heißt die Seite `/downloads`, darf im Bundle kein Ordner `downloads/` liegen: Ein Name auf oberster Ebene ist entweder Seite oder Asset-Ordner. Das prüft `npm run validate` nicht; der Fehler zeigt sich erst beim Rendern nach dem Upload.
