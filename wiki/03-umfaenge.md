# 03 · Die drei Umfänge

[Übersicht](README.md) › 03 · Die drei Umfänge

| Umfang                  | Was                                                                                                           | Vorteil                                                                                                                       | Preis                                                                                           |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| **One-Pager**           | Eine Seite, alles als Sections, Menü als Anker oder gar keins, Rechtliches als Unterseiten                    | Schnell gebaut, alles auf einen Blick, keine leeren Unterseiten, ideal für Save-the-Date, Messe-QR, Warteliste, kleine Events | Wird lang, wenn das Event viel hat; jede Section konkurriert mit dem CTA; wenig Tiefe für Suche |
| **Multipage klassisch** | Startseite plus die Standardseiten, die das Event braucht, Daten aus Streavent                                | Jede Seite beantwortet eine Frage, teilbare URLs, Programm und Speaker haben Platz                                            | Jede Seite muss Inhalt haben, sonst Empty-State; Menü und Footer müssen gepflegt werden         |
| **Multipage groß**      | Zusätzlich Themen-Seite, Seiten je Zielgruppe, dynamische Detailseiten, Content-Hub, Downloads, eigene Blöcke | Trägt eine Marke, mehrere Publika, Presse, Community, Sub-Events; stark für Suche und KI-Antworten                            | Redaktion nötig, viele Collections, mehr Pflege beim Kunden                                     |

Ein One-Pager kann später zum Multipage wachsen. Deshalb Tokens, Partials und Feldschlüssel von
Anfang an so anlegen, als würde er es.

Je ein Beispiel: [Save-the-Date](beispiele/save-the-date.md) · [Kleines Event](beispiele/kleines-event.md) · [Kongress](beispiele/kongress.md) · [Konferenz groß](beispiele/konferenz-gross.md) · [Messe](beispiele/messe.md)
