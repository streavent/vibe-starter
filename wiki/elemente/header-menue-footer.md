# Header, Menü, Footer

[Übersicht](../README.md) › [Elemente](README.md) › Header, Menü, Footer

## Header

Logo links, verlinkt auf die Startseite; Menü; Ticket-CTA rechts als Button, nicht als Menüpunkt;
daneben "Login" oder "Bereits registriert?" als Link in die Event-App oder Plattform, sichtbar erst
ab Registrierungsstart; klebend beim Scrollen; Skip-Link zum Inhalt; Sprachumschalter nur bei
mehreren Sprachen. Am Handy: Burger, Overlay mit allen Punkten und Untergruppen, Ticket-CTA als
letztes Element, dazu die Kontakt-Mail. Ein One-Pager kann auf ein Menü verzichten oder Anker
nutzen.

## Menü

So wenige Punkte wie möglich; was nicht ins Menü passt, gehört in den Footer. Die Punkte tragen die
Worte des Kunden (Referenten oder Speaker, Sponsoren oder Partner). Ein Menüpunkt erscheint erst,
wenn die Seite Inhalt hat.

| Menüpunkt                        | Wann sinnvoll                             | Untergruppe, wenn es sie gibt                            |
| -------------------------------- | ----------------------------------------- | -------------------------------------------------------- |
| Programm                         | sobald es eine Programmseite gibt         | Übersicht, Themenbereiche, Side Events, Abendevent       |
| Speaker / Referenten             | sobald Speaker gezeigt werden             | Aktuell, Vorjahr, Call for Papers                        |
| Sponsoren & Partner              | sobald es eine Partnerseite gibt          | Partner, Sponsor werden, Aussteller werden               |
| Aussteller                       | bei einer Ausstellung                     | Verzeichnis, Hallenplan, Aussteller werden               |
| Tickets / Teilnehmen             | immer, aber als Button                    | Kategorien, Warteliste, Bewerbung                        |
| Warum / Thema                    | wenn es eine Themen-Seite gibt            |                                                          |
| Für wen                          | bei mehreren Publika mit eigenen Seiten   | eine Zeile je Zielgruppe                                 |
| Mitwirken                        | bei mehreren Wegen, mitzumachen           | Sponsor, Aussteller, Speaker, Volunteer, Side Event      |
| Mediathek / Rückblick / Insights | bei Material aus Vorjahren oder Redaktion | Bilder, Videos, Blog, Podcast, Presse                    |
| Service / Infos / Ihr Besuch     | wenn Anreise, Hotels, FAQ erklärt werden  | Anreise, Hotels, Stadt, FAQ, Presse, Kontakt, Newsletter |
| Events                           | bei mehreren Veranstaltungen              | ein Eintrag je Veranstaltung                             |

## Footer

Zwei Teile: der Abschluss (Statement oder Datum und Ort, Ticket-CTA, zweiter CTA wie "Sponsor
werden" oder "Zum Programm", Newsletter) und die Leiste mit allem, was man sucht. Der Footer ist auf
jeder Seite der letzte Blick, deshalb stehen Datum und Ort dort noch einmal.

| Footer-Block           | Inhalt                                                                                                                    | Hinweis                                                    |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Seiten                 | Die Hauptseiten, mit einem Wort dazu, was dort steht                                                                      | Was im Menü fehlt, steht hier                              |
| Mitwirken und Material | Sponsor werden, Call for Papers, Aussteller werden, Downloads, Media-Kit, Partner-Paket                                   | Downloads als Zip, nicht als Einzeldateien                 |
| Service                | Anreise, Hotels, FAQ, Presse, Kontakt                                                                                     |                                                            |
| Kontakt                | Mail des Events, Ansprechpersonen mit Rolle, Telefon; Adresse des Veranstalters                                           | Foto macht den Unterschied                                 |
| Social                 | Icons der aktiven Kanäle                                                                                                  | Nur Kanäle, die bespielt werden                            |
| Veranstalter           | "ermöglicht durch" oder "eine Veranstaltung von", Förderer, Mitveranstalter                                               | Eigene Marke des Veranstalters, siehe [Marke](../marke.md) |
| Rechtsleiste           | Impressum, Datenschutz, AGB oder Teilnahmebedingungen, Code of Conduct, Cookie-Einstellungen, Copyright, Plattformhinweis | Cookie-Einstellungen, wenn ein Consent-Tool läuft          |

Fünf Beispiele für Menü und Footer stehen in den [Beispielen](../beispiele/README.md).
