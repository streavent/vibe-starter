<sv-agenda> — Embed Demo

One bundle (@streavent/sv-runtime, ~20 KB), three usages. Fetch is stubbed locally so it renders with no backend. Open the console to see the stubbed requests.

1. Zero-config (default template + default CSS)

Just the tag — copy & paste, works immediately.

2. Restyled via CSS custom property (--sv-accent)

Same default markup, different accent — no template needed.

3. Fully custom template (renderless)

Consumer supplies its own markup; the component only binds data.
